# Экзаменариум

Интерактивный тренажёр для подготовки к государственному экзамену и ВАК по психологии.

## Что внутри

- 70 экзаменационных билетов по 13 разделам;
- краткий каркас, полный конспект и план устного ответа;
- карточки с самооценкой сложности;
- викторина на различение близких тем;
- 35 практических кейсов с алгоритмом разбора;
- таймер и чек-лист для репетиции ответа комиссии;
- локальный прогресс без регистрации;
- отдельный раздел с аудитом и ограничениями исходных материалов.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Проект открывается на адресе, который выведет dev-сервер. Для проверки production-сборки:

```bash
pnpm lint
pnpm exec next build
```

## Данные

Учебный корпус находится в `public/data/study-content.json`, аудит источников — в `public/data/source-audit.json`. Нумерация и названия билетов сверены с официальной программой ГЭК. Архивные решения кейсов помечены отдельно и не выдаются за единственно верные.

Прогресс хранится в `localStorage` браузера под версионированным ключом `examarium-progress-v1`.

## Деплой

Конфигурация `vercel.json` собирает проект как стандартное приложение Next.js на Vercel.
